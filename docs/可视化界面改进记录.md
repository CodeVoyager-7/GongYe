# 可视化界面改进记录

## 1. 改进目标

原有 `Streamlit` 页面偏向实验结果展示，本轮将其升级为更适合比赛演示的“智能预测与排放监测平台”原型。

## 2. 已完成改进

### 2.1 监控大屏首页

新增“装置运行监控大屏”，突出平台感：

- 当前装置状态
- 当前最优模型
- `y1/y2` 最优 R2
- warning 点数
- danger 点数
- 最近高风险目标与时间步

### 2.2 模型演进模块

将原模型表格升级为模型演进展示：

- 静态回归：`XGBoost`
- 时滞建模：`XGBoost-lag`
- 深度时序：`SLSTM`
- 变量 token 建模：`iTransformer-style`

该模块用于支撑答辩叙事：

> 静态建模不足，时滞建模有效，深度时序模型进一步提升，iTransformer-style 当前最优。

### 2.3 交互式风险预警

风险模块新增交互能力：

- 按目标变量筛选：`y1/y2`
- 按风险等级筛选：`warning/danger`
- 控制告警明细展示数量
- 展示告警时间线
- 保留风险曲线与误差异常曲线

### 2.4 卡片式辅助决策建议

辅助决策模块由表格展示升级为卡片展示：

- 目标变量
- 风险等级
- 关注变量
- 滞后步长
- 优先级
- 触发原因
- 建议动作

该模块更适合答辩现场展示，也更贴近“辅助决策支持”要求。

### 2.5 交互式预测曲线

预测曲线由静态图片升级为 Plotly 交互式图表：

- 支持选择模型：`iTransformer`、`SLSTM`、`VA-LSTM`、`XGBoost-lag`
- 支持选择目标变量：`y1/y2`
- 支持滑块选择展示时间步区间
- 支持悬停查看真实值与预测值
- 保留原静态图片作为折叠兜底展示

### 2.6 风险阈值配置面板

风险预警模块新增阈值配置：

- 支持调整 warning 分位阈值
- 支持调整 danger 分位阈值
- 根据当前阈值动态更新风险曲线
- 支持按目标变量查看交互式风险曲线

### 2.7 模拟实时推演

监控大屏新增模拟实时推演模块：

- 支持选择监控目标 `y1/y2`
- 支持手动定位时间步
- 支持从关键风险点中快速选择
- 展示当前预测值、真实值、绝对误差、风险等级
- 自动匹配当前风险点对应的辅助决策建议
- 展示当前时间步附近的交互式风险曲线

## 3. 当前页面结构

当前页面包含：

1. 装置运行监控大屏
2. 模拟实时推演
3. 延迟响应分析
4. 模型演进与性能对比
5. 交互式预测曲线展示
6. 异常检测与风险阈值配置
7. 辅助决策建议
8. 下一步路线

## 4. 后续仍可优化

1. 增加自动播放按钮，按固定速度自动推进时间步。
2. 增加系统架构页面，展示数据层、模型层、预警层和应用层。
3. 增加专家知识库配置文件，替代当前硬编码建议规则。
4. 增加模型解释页面，展示变量注意力或特征贡献。
5. 增加一键导出答辩截图和实验报告功能。
