# 实验结果与阶段性结论

## 1. 文档说明

本文档用于总结当前阶段围绕 `SRU` 数据集开展的建模实验、结果对比和阶段性结论，可直接用于后续申报书撰写、PPT 制作和答辩陈述。

## 2. 数据集说明

当前实验使用公开 `SRU` 数据集，即 `Sulfur Recovery Unit` 硫回收装置软测量数据集。

- 数据文件：[sru_openml.csv](C:/Users/lenovo/Desktop/人工智能大赛/data/raw/sru/sru_openml.csv)
- 样本数：`10081`
- 字段数：`7`
- 输入变量：`a1-a5`
- 输出目标：`y1`、`y2`

当前实验将任务定义为：

- 基于多变量工业过程数据预测 `y1` 和 `y2`
- 对比静态回归、时滞特征回归和深度时序模型的效果差异

## 3. 实验目标

本阶段实验的核心目标有三个：

1. 验证 SRU 任务是否适合使用普通静态回归建模。
2. 验证 SRU 数据中是否存在明显的时滞关系。
3. 验证深度时序模型是否优于传统回归模型。

## 4. 实验方法设计

### 4.1 静态 baseline

第一组实验采用 `XGBoost` 对当前时刻输入变量直接进行双目标回归，不引入历史窗口和 lag 特征。

目的在于验证：

- 如果把 SRU 问题看成普通回归任务，模型效果如何。

### 4.2 时滞特征 baseline

第二组实验在 `XGBoost` 基础上加入人工构造的 lag 特征，当前使用：

- `lags = [1, 3, 5, 7]`

即为每个输入变量构建多个历史滞后版本，用于增强动态过程表达能力。

目的在于验证：

- 加入延迟信息后，模型是否有明显提升。

### 4.3 深度时序模型

第三组实验采用监督式 `LSTM` 序列回归模型 `SLSTM`，使用长度为 `12` 的时间窗口作为输入，直接学习多变量时间依赖关系。

模型相关文件：

- [SLSTM 模型](C:/Users/lenovo/Desktop/人工智能大赛/src/models/advanced/slstm_model.py)
- [SLSTM 训练脚本](C:/Users/lenovo/Desktop/人工智能大赛/src/training/train_slstm.py)

目的在于验证：

- 深度时序模型能否进一步提升对 `y1`、`y2` 的预测能力。

## 5. 时滞分析结果

在正式做深度时序建模前，我们先对 `SRU` 数据集进行了 lag 相关性分析。

输出文件如下：

- [相关性热图](C:/Users/lenovo/Desktop/人工智能大赛/outputs/figures/sru_correlation_heatmap.png)
- [y1 lag 热图](C:/Users/lenovo/Desktop/人工智能大赛/outputs/figures/sru_lag_heatmap_y1.png)
- [y2 lag 热图](C:/Users/lenovo/Desktop/人工智能大赛/outputs/figures/sru_lag_heatmap_y2.png)
- [最佳 lag 汇总表](C:/Users/lenovo/Desktop/人工智能大赛/outputs/tables/sru_best_lag_summary.csv)

最佳 lag 结果显示：

- `a3 -> y1` 的最佳 lag 为 `12`，相关系数约为 `-0.1558`
- `a2 -> y2` 的最佳 lag 为 `6`，相关系数约为 `0.1580`
- `a3 -> y2` 的最佳 lag 为 `12`，相关系数约为 `0.1570`
- `a1 -> y2` 的最佳 lag 为 `12`，相关系数约为 `0.1430`

这说明：

- `SRU` 输出变量与输入变量之间存在明显的时滞关系
- 不同目标变量对应的关键滞后步长并不一致
- 仅使用当前时刻输入变量进行静态回归并不充分

## 6. 模型结果对比

汇总结果文件如下：

- [模型对比表](C:/Users/lenovo/Desktop/人工智能大赛/outputs/tables/model_comparison_metrics.csv)

### 6.1 静态 XGBoost 结果

测试集结果：

- `y1`: `MAE = 0.0442`，`RMSE = 0.0660`，`R2 = -0.4543`
- `y2`: `MAE = 0.0711`，`RMSE = 0.0938`，`R2 = -1.5308`

结果说明：

- 静态回归表现较差
- 对两个目标变量均无法有效拟合
- 说明 SRU 问题并不适合直接当作普通表格回归问题处理

### 6.2 XGBoost + lag 特征结果

测试集结果：

- `y1`: `MAE = 0.0249`，`RMSE = 0.0382`，`R2 = 0.5126`
- `y2`: `MAE = 0.0449`，`RMSE = 0.0609`，`R2 = -0.0676`

结果说明：

- 引入 lag 特征后，`y1` 的预测性能显著提升
- `y2` 也有明显改善，但仍未达到理想水平
- 说明人工构造时滞特征是有效的，但模型表达能力仍有上限

### 6.3 SLSTM 结果

测试集结果：

- `y1`: `MAE = 0.0222`，`RMSE = 0.0337`，`R2 = 0.6213`
- `y2`: `MAE = 0.0243`，`RMSE = 0.0316`，`R2 = 0.7127`

结果说明：

- `SLSTM` 在两个目标上都优于静态 `XGBoost`
- `SLSTM` 也优于 `XGBoost + lag`，尤其是 `y2` 的提升非常明显
- 说明使用序列模型直接建模历史窗口，能够更充分地挖掘工业过程中的动态耦合关系

## 8. 阶段性结论

基于当前实验结果，可以得到以下阶段性结论：

1. `SRU` 数据集具有明显的动态时序特征，不适合仅用静态回归建模。
2. lag 分析表明输入变量与输出变量之间存在显著延迟响应关系。
3. 加入时滞特征后，传统模型性能明显改善，说明“延迟响应分析”是正确方向。
4. `SLSTM` 在当前实验中取得了最优结果，特别是在 `y2` 预测上表现突出。
5. 当前实验已经验证了项目的核心技术路线，即“多变量时序建模 + 延迟响应分析”具有可行性。
