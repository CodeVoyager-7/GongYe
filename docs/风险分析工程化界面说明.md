# 风险分析工程化界面说明

本文档记录风险分析相关界面的定位、操作入口和维护边界。界面面向装置值班、工艺复核和告警闭环人员使用，说明性内容统一放在本文档中，不放在生产监控界面主流程内。

## 1. 界面定位

- 风险监控台：用于查看 H2S / SO2 浓度趋势、阈值线、报警事件和当前采样点状态。
- 智能报警处置台：用于查看待处置报警、优先级、触发原因、重点检查项和处置动作。
- 风险分析配置与闭环：用于在线判定、阈值管理、专家规则审计和工单闭环。

## 2. 阈值管理

阈值管理用于维护风险判定标准。当前系统将风险分为正常、预警、危险三类，分别由浓度阈值和误差阈值共同判定。

- 预警浓度阈值：预测浓度达到该值后进入预警关注。
- 危险浓度阈值：预测浓度达到该值后进入危险处置。
- 预警误差阈值：模型误差达到该值后提示结果需要重点复核。
- 危险误差阈值：模型误差达到该值后进入高风险复核。

阈值修改需要填写调整原因，系统会写入阈值版本记录，便于后续追溯。

## 3. 专家规则

专家规则用于把模型风险结果转成工程可执行信息。规则应尽量保持短句、明确、可检查。

建议每条规则包含：

- 监控指标：尾气 H2S 或尾气 SO2。
- 风险等级：正常、预警或危险。
- 关注场景：例如配风不足、过量配风、仪表漂移、负荷扰动。
- 触发条件：规则命中的条件表达式。
- 现场检查项：具体到空气量、酸气负荷、反馈回路、在线分析仪等对象。
- 处置动作：值班人员可以执行或提交确认的动作。
- 可信度和校核说明：说明规则是否已通过数据或工程经验复核。

## 4. 工单闭环

工单闭环用于把连续报警整理成可追踪事件。建议现场使用时按以下顺序处理：

1. 确认报警指标、采样时间、风险等级和优先级。
2. 复核在线分析仪、酸气负荷、空气量和关键控制回路。
3. 根据规则建议执行调整或提交人工确认。
4. 更新处置状态、负责人、处理备注和复盘结论。
5. 对误报、传感器异常、工况切换等情况进行留痕，供后续阈值和规则优化使用。

## 5. 维护原则

- 生产界面只保留操作所需信息，不放答辩、演示、教学式说明。
- 规则和阈值说明放在文档或配置记录中。
- 表格列名尽量使用中文，避免暴露 `a1-a5`、`warning`、`danger` 等内部字段。
- 原始审计信息可以折叠展示，但不作为主界面默认内容。
